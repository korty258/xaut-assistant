## 第五条 Cookie 与内嵌浏览器说明

5.1 本软件通过**系统内嵌浏览器组件**（Android System WebView / Microsoft Edge WebView2）加载教务系统页面。

5.2 教务系统为维持登录状态会向浏览器下发 **Cookie**。该 Cookie 由学校服务器设置，存储于内嵌浏览器的本地数据目录中，**本软件的业务代码不读取、不解析、不上传该 Cookie**。

5.3 该 Cookie 会在您的设备上保留一段时间，使您下次打开软件时无需重新登录。**这是便利性与安全性的权衡**：在共用设备上，他人可能在您未退出时直接看到您的课表与成绩。

5.4 您可以通过以下方式终止该会话：

- 使用软件内的清除功能；
- 卸载本软件（将一并删除内嵌浏览器的全部本地数据）；
- 在 Windows 端删除 `%APPDATA%` 下本软件对应的应用数据目录。

5.5 本软件**自身不设置任何 Cookie**，也不使用 Cookie 进行追踪、画像或广告投放。

## 第六条 信息的存储

### 6.1 存储地点

全部数据存储于**您的设备本地**，具体位置：

| 平台 | 存储位置 | 说明 |
|---|---|---|
| Android | 应用私有目录 `/data/data/<包名>/shared_prefs/` 与 `files/` | 受 Android 应用沙箱保护，其他应用无法直接读取（除非设备已 root） |
| Android | 内嵌 WebView 数据目录 | 存储教务系统 Cookie |
| Windows | `%APPDATA%\<应用标识>\` 下的 JSON 文件 | 当前用户配置目录 |
| Windows | WebView2 用户数据目录 | 存储教务系统 Cookie 与网页缓存 |

**本软件不存在任何远程存储。** 我们没有任何数据库、对象存储或日志服务器。

### 6.2 存储方式

当前版本将课表、成绩、考试数据以 **JSON 明文**形式写入上述私有目录，未做加密。我们如实告知这一事实及其含义：

- **有利面**：数据处于操作系统应用沙箱内，普通应用无法读取；Android 上其他应用需 root 权限方可访问。
- **风险面**：在设备已 root、开启 USB 调试并被授权、或系统备份被导出的情形下，明文数据可能被提取。Windows 端同一账户下的其他程序可直接读取该目录。
- **改进计划**：我们计划在后续版本中将对成绩与课表明文缓存升级为**加密存储**（Android Keystore / Windows DPAPI 托管密钥）。在该改进完成前，请您避免在共用或不可信设备上使用本软件。

### 6.3 存储期限

| 数据 | 保留期限 | 删除方式 |
|---|---|---|
| 课表、成绩、考试缓存 | 直至您主动清除、下次同步覆盖，或卸载软件 | 模块内"清空"、卸载软件 |
| 教学周与偏好设置 | 同上 | 同上 |
| 登录会话 Cookie | 由学校服务器的 Cookie 有效期决定，或直至您清除浏览器数据 | 清除本地数据、卸载 |
| 上次同步时间 | 同上 | 同上 |

我们**不设**独立的"数据保留期"，因为数据不在我们控制之下；保留多久完全由您决定。

### 6.4 跨境传输

**本软件不向境外提供您的任何个人信息。** 全部处理均发生在您的设备上，我们不进行任何数据出境活动。

8.3.1 由于本软件不运营服务器、不收集数据，**通常不会发生由我们引起的个人信息泄露事件**。可能的安全事件主要源于您的设备侧（设备丢失、被入侵、被他人使用）。
