# 金花助手隐私政策

> **生效日期**：2026 年 10 月 31 日 ｜ **适用版本**：v2.0 及后续版本 ｜ **运营主体**：个人开发者 korty258（本应用为纯端侧本地工具，开发者不接收、不收集个人信息）

---

## 摘要（一分钟读懂）

- **零服务器 / 零云端上传**：本软件没有自建后端服务器，不存在向开发者或任何第三方服务器回传数据的通道。
- **绝不收集密码**：登录过程完全发生在学校官方网页表单内，本软件不拦截、不记录、不存储您的密码。
- **无第三方统计 SDK**：不集成任何商业统计、广告推广、行为追踪或社交分享组件。
- **本地化安全沙箱**：课表、成绩与考试数据仅在您的设备本地缓存；已在 Android 端显式关闭系统备份（`allowBackup="false"`），杜绝通过系统备份导出泄露。
- **随时撤回同意与清空数据**：您可随时在软件内“关于与法律条款”中行使《个人信息保护法》第 15 条赋予的撤回权，一键销毁本地全部缓存并恢复未授权状态。

## 第一条 基本原则与适用范围

1.1 本隐私政策适用于“金花助手”（Android 版与 Windows 桌面版）及其后续版本。

1.2 我们在产品设计中深度参照《中华人民共和国个人信息保护法》（PIPL）、《中华人民共和国数据安全法》及网络安全法律法规的相关原则，恪守“**最小必要**”与“**本地优先**”原则处理您的信息。

1.3 **请在使用前完整阅读本政策**。通过首次启动门禁勾选确认，即表示您已阅读并同意本政策全部内容。如您不同意，请立即退出并卸载本软件。

## 第二条 我们处理的信息类型与目的

为了向您提供课表日程排布、成绩绩点分析及考试安排速查服务，本软件仅在**您的设备本地**处理以下信息：

| 信息类别 | 包含字段 | 来源渠道 | 处理目的 | 是否离开您的设备 |
| :--- | :--- | :--- | :--- | :---: |
| **课表信息** | 课程名、代码、任课教师、教室地点、节次、周次 | 经您登录后的官方教务课表页 | 本地智能排课、仅本周/所有周展示 | **否** |
| **成绩信息** | 课程名、成绩、学分、绩点、课程属性、学期 | 经您登录后的官方教务成绩页 | 本地成绩列表展示、动态 GPA 绩点重算 | **否** |
| **考试信息** | 考试科目、起止时间、考场地点、监考老师 | 经您登录后的官方教务考试页 | 待考优先智能排序、起止倒计时角标 | **否** |
| **教学周信息** | 当前学期（如 2026-2027-1）、教学周、开学周一日期 | 教务系统顶栏及周历页面 | 自动校准当前教学周、日期推算 | **否** |
| **界面配置** | 选定周次、仅本周/所有周开关、签署同意记录 | 本地用户操作 | 记忆您的界面交互偏好与合规记录 | **否** |
| **登录会话** | 教务系统下发的会话 Cookie | 学校教务系统服务器 | 维持系统内嵌网页登录状态，避免频繁重复登录 | **否** |

## 第三条 我们明确不收集的信息

为消除疑虑，我们特别声明本软件**坚决不收集、不记录、不上报**下列任何敏感数据：

1. **教务登录密码**：您在学校官方页面输入框中输入密码，本软件不注入任何键盘监听脚本，密码绝不会写入日志或持久化文件。
2. **敏感个人身份**：不采集身份证号、手机号、银行账户、通讯录、短信等无关信息。
3. **设备高级标识与定位**：不读取 IMEI、OAID、Android ID 等硬件设备指纹，不请求 GPS 地理位置权限。
4. **设备私密资源**：不访问您的相册、相机、麦克风或剪贴板。

## 第四条 系统权限与第三方 SDK 清单

4.1 **系统权限申请**：

4.2 **第三方组件说明**：
- **本软件不包含任何第三方商业 SDK**（包括但不限于友盟、极光推送、百度移动统计、腾讯 Bugly、穿山甲广告等）。
- 本软件所采用的依赖库（Flutter Framework、Provider、SharedPreferences、WebView 组件）均为**本地运行的开源功能组件**，不具备任何向外部回传数据的功能。

## 第五条 数据存储与安全保护机制

5.1 **存储位置**：全部数据均保存在您设备的私有沙箱中：
- Android 端：位于系统私有沙箱目录 `/data/data/io.github.korty258.jinhua_assistant/`，受 Android 沙箱机制隔离保护；
- Windows 端：位于当前系统用户的本地配置应用目录中。

5.2 **安全防护加固**：
- **关闭系统备份**：Android 宿主已配置 `android:allowBackup="false"`，杜绝本地数据被系统自动备份或通过 ADB 备份指令提取导出。
- **全链路 HTTPS 加密**：所有与教务系统的网络通信均被强制限定在 HTTPS 协议下进行，不启用明文 HTTP 传输。
- **源码完全公开透明**：项目全部源代码已在 GitHub 开源，任何人均可审查其数据处理逻辑。

5.3 **保存期限**（PIPL 第 17 条）：本应用产生的所有本地缓存数据（课表、成绩、考试日程、协议签署状态）均仅保存在用户当前设备本地，保存期限为用户主动清除、在应用内撤回知情同意或卸载应用之前；一旦用户在应用内执行撤回知情同意操作或点击清空数据，本地留存的数据将被立即彻底删除。

5.4 **安全事件应急响应与告知**（PIPL 第 57 条）：鉴于本软件为纯端侧本地工具、不设云端账户体系与用户统一推送通道，若开发者发现客户端存在安全缺陷或本地存储泄露风险，将通过 GitHub Releases、仓库安全公告（Security Advisory）及 README 显著位置发布安全通报与修复版本，说明安全处置进展；用户亦可通过专门的安全沟通邮箱 `korty666@outlook.com` 报告漏洞与核实进展。

## 第七条 您的权利（行使与撤回知情同意）

依据《中华人民共和国个人信息保护法》第四章规定，您对个人信息享有充分的法定权利：

1. **查阅与核对权**（PIPL 第 44/45 条）：您可在课表、成绩、考试页面随时直接查阅全部由教务系统同步并存储在本地的数据。
2. **复制与导出权**（PIPL 第 45 条）：您有权获取您在设备本地存储的个人信息副本。本应用支持将本地已解析的日程及学业数据进行复制、查看或导出。
3. **更正与补充权**（PIPL 第 46 条）：由于本应用展示的课表、成绩、考试日程均忠实呈现自学校官方教务系统前端页面，若您发现相关信息存在错误或遗漏，请首先在学校官方教务系统中完成信息更正，随后在本应用内重新执行一键同步，本地缓存将立即更新覆盖。
4. **清除本地数据权**（PIPL 第 47 条）：您可随时在各功能模块菜单中点击“清空数据”删除相应模块的本地数据缓存。
5. **撤回知情同意权（PIPL 第 15 条）**：
   - 您可在软件任意界面的“关于与法律条款”中点击右上角的“**撤回同意**”按钮；
   - 确认撤回后，软件将立即清除保存在本机设备上的所有已解析业务数据（课表、成绩、考试）、用户偏好、授权存证及登录 Cookie，并安全退回到首次启动门禁；
   - **多端数据销毁与清理说明**：
     - **Android 移动端**：点击“撤回同意”时，应用将清空 SharedPreferences 本地持久化数据库、调用底层 Cookie 管理器抹除登录会话，并递归清理应用缓存沙盒；卸载应用时系统将自动清空应用私有沙盒全部数据。
     - **Windows 桌面端**：撤回时将清除本地数据库与用户配置并尝试删除缓存；由于采用免安装绿色便携运行机制，底层 WebView2 进程在运行时可能独占锁定部分临时网络缓存，如需彻底消除痕迹，建议在退出程序后手动删除程序同级目录下的 `*.WebView2` 文件夹及 `%APPDATA%\io.github.korty258.jinhua_assistant` 目录。我们不承诺在 Windows 端“运行时立即 100% 物理粉碎全部被占用缓存文件”。
6. **咨询、投诉与处理时限承诺**（PIPL 第 50 条）：
   - 您如对个人信息处理规则有任何疑问、投诉、建议或主张行使法定权利，可通过公开邮箱 `korty666@outlook.com` 与开发者联系；
   - 开发者承诺在收到您的核实请求后 **15 个工作日内** 完成核查并予以答复处理。
